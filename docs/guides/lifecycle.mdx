---
title: Errors and session lifecycle
description: Own contexts, connections, credentials, and typed failures explicitly.
---

The reusable client retains configuration and one shared MQTT connection per account, not account tokens. Every account request supplies `AuthContext`. The connection is keyed by the MQTT credentials of the request that opened it and serves all of that account's devices; each opened device session is a borrow of it with its own pending RPCs. `Close` returns the borrow and is safe to call repeatedly; a device subscription lingers for 60 seconds after its last borrow and the connection closes with the last subscription (`WithMQTTIdleTimeout` adjusts this). `Client.Close` ends every connection. A dropped connection reconnects on the next `OpenDevice`; consecutive failed connects back off from 10 seconds by a factor of 1.5, capped at 5 minutes. When the broker refuses the credentials, `OpenDevice` returns an `Unauthorized` error without contacting the broker again until different credentials are supplied. Canceling the opening context closes the session and unblocks pending calls. Observe `session.Done()` for termination caused by cancellation, close, heartbeat expiry, or connection failure.

Use a long-lived cancellable context for session ownership and a fresh deadline for each operation. Sessions enforce heartbeat liveness, expire unanswered requests, reject connection failures, and bound pending work. Backpressure means the session cannot accept more work; reduce concurrency or close the owner as appropriate.

```go
var failure *roborockerrors.Error
if errors.As(err, &failure) {
    switch failure.Kind {
    case roborockerrors.Unauthorized:
        // Explicitly obtain replacement credentials.
    case roborockerrors.Timeout:
        // A sent control command may have taken effect.
    case roborockerrors.Backpressure:
        // Reduce pending work before another attempt.
    }
}
```

Other classes include `InvalidArgument`, `NotFound`, `RateLimited`, `Unavailable`, `Canceled`, `Protocol`, `Closed`, and `Unsupported`. The error preserves its underlying cause for `errors.Is` and `errors.As` without exposing raw response bodies as its message. Keep secrets out of your own logs.

Inject HTTP with `WithHTTPClient` and MQTT connections with `WithMQTTDial`. Injected transports must honor cancellation and own their security configuration. Cleanup remains the session owner's responsibility.
