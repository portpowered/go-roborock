---
title: Use the CLI
description: Log in, find your vacuum, read its map, and start cleaning.
---

## 1. Install

```sh
go install github.com/portpowered/go-roborock/cmd/go-roborock@latest
```

Make sure Go's binary directory is on your `PATH` so you can run `go-roborock`.

## 2. Log in

```sh
go-roborock login
```

Enter your Roborock account email when prompted, then enter the code sent to that email. The CLI handles the login exchange and saves your account locally for subsequent commands.

## 3. Find your vacuum

```sh
go-roborock devices list
```

Copy your vacuum's device ID from the result. Replace `DEVICE_ID` in the following commands with that ID.

## 4. Check the vacuum and its map

```sh
go-roborock devices vacuum DEVICE_ID status
go-roborock maps show --device DEVICE_ID
go-roborock rooms list --device DEVICE_ID
```

`maps show` reads the current map. To list saved maps, run `go-roborock maps list --device DEVICE_ID`. Q7 devices also support reading a saved map with `go-roborock maps show MAP_ID --device DEVICE_ID`; replace `MAP_ID` with an ID from that list.

Status and available controls depend on the [device family](/docs/guides/device-families). Use `go-roborock devices vacuum DEVICE_ID capabilities` to check supported operations.

## 5. Start, pause, or return to the dock

Run the command for the action you want:

```sh
go-roborock devices vacuum DEVICE_ID start
go-roborock devices vacuum DEVICE_ID pause
go-roborock devices vacuum DEVICE_ID dock
```

These commands move the vacuum. A successful command does not mean cleaning or docking has finished.

To clean a particular room, choose its ID from `rooms list`:

```sh
go-roborock rooms clean ROOM_ID --device DEVICE_ID
```

For rectangle cleaning, see [zone cleaning](/docs/guides/zone-cleaning) before choosing coordinates. Use `go-roborock help` to see all commands.

## 6. Log out when finished

```sh
go-roborock logout
```

Logout removes the saved account from this computer. The default profile is `go-roborock/profile.json` under your operating system's user configuration directory; it contains credentials, so keep that directory private. Use `--profile PATH` on each command to choose a different profile.
