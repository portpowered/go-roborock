---
title: Get started
description: Authenticate, discover a device, and choose its supported operations.
---

Install `github.com/portpowered/go-roborock` and import `pkg/roborock`. Start with [authentication](/docs/guides/authentication), then [discovery](/docs/guides/discovery).

Check [device families](/docs/guides/device-families) before choosing [vacuum controls](/docs/guides/vacuum), [maps](/docs/guides/maps), [zone cleaning](/docs/guides/zone-cleaning), or [A01 settings](/docs/guides/a01). Use [camera signaling](/docs/guides/camera) on capable V1 devices.

The [CLI](/docs/guides/cli) offers explicit read and control commands. Read [errors and lifecycle](/docs/guides/lifecycle) before keeping a session open.

The OpenAPI reference covers cloud HTTP requests. The AsyncAPI reference covers MQTT commands and messages. Public Go request fields are documented in Go Reference and the linked type guides.

Contracts follow pinned implementation references and synthetic offline tests. They are not an official vendor specification or a claim of complete Python parity; device captures remain separate compatibility evidence.
